# 3–8 Minute Demo Script

1. Show the folder structure.
2. Explain `data/`, `src/`, `ingest.py`, and `app.py`.
3. Run `python ingest.py` and show PDF pages, chunks, embeddings, and ChromaDB storage.
4. Run `streamlit run app.py`.
5. Ask at least five questions covering multiple documents.
6. Expand the retrieved source chunks and show filename/page citations.
7. Ask a question not covered by the documents and show the grounded fallback.
8. Explain the 1000-character / 150-character-overlap chunking decision and persistent ChromaDB choice.
